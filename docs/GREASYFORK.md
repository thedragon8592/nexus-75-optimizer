## Full description — English

Nexus 75 Optimizer is a transparent performance userscript for survev.io and
resurviv.biz. It aims for stable performance up to 75 visible FPS while reducing
unnecessary CPU, GPU and background work.

The futuristic control panel opens automatically when the game loads. Press F8
to hide or show it. English is the default language and the EN/ES selector
translates the complete interface to Spanish.

Features:

- Quality, Balanced, FPS, Competitive, Extreme and Original profiles.
- Uses the low-resolution texture atlases already included by the games.
- Optional 1x rendering on HiDPI displays, reducing the number of rendered
  pixels by up to four times compared with the games' 2x mode.
- Reduces lobby animations and prevents hidden lobby elements from being
  composited during matches.
- Four-second visible-lobby auto-tuner with a seven-day device cache.
- Smart Region reuses the region chosen by the games' official tests for up to
  72 hours and adds no ping requests.
- FPS, 1% low, p95 frame time, long-task and optional input-to-frame metrics.
- Stops its monitor when the panel or browser tab is hidden.
- Captures the original game configuration and provides a reversible Original
  mode.
- Built-in “How it works” explanation for every optimization.

This script does not modify WebSocket packets, matchmaking, aiming, hitboxes,
visibility or game mechanics. It does not replace requestAnimationFrame with
busy timers and does not create fake ping requests.

Every fifth game opening displays a large, dismissible Nexus Chat welcome
dialog in English. It honestly previews automatic match rooms, Global, a
persistent Nexus ID, friends and private conversations. “Explore Nexus Chat”
opens only the official website at https://wnexuschat.netlify.app/ and requires
an explicit click; the userscript never downloads a file. The × and “Not now”
buttons dismiss only the current appearance. There is no tracking, affiliate
link, external executable code or automatic redirect.

## Descripción completa — Español

Nexus 75 Optimizer es un userscript transparente de rendimiento para survev.io
y resurviv.biz. Su objetivo es conseguir un rendimiento estable de hasta 75 FPS
visibles, reduciendo trabajo innecesario de CPU, GPU y procesos visuales en
segundo plano.

El panel futurista se abre automáticamente al cargar el juego. Pulsa F8 para
ocultarlo o mostrarlo. El idioma inicial es inglés y el selector EN/ES traduce
toda la interfaz al español.

Funciones:

- Perfiles Calidad, Balance, FPS, Competitivo, Extremo y Original.
- Utiliza los atlas de texturas low que ya incluyen los juegos.
- Render 1x opcional en pantallas HiDPI, reduciendo hasta cuatro veces los
  píxeles dibujados frente al modo 2x de los juegos.
- Reduce animaciones del lobby y evita componer elementos ocultos durante una
  partida.
- Auto-tuner de cuatro segundos visibles en el lobby, con caché de siete días
  por dispositivo.
- Región Inteligente reutiliza hasta 72 horas la región elegida por las pruebas
  oficiales del juego y no genera pings propios.
- Métricas de FPS, 1% low, p95 de frame, tareas largas y entrada al siguiente
  frame opcional.
- Detiene su monitor cuando se oculta el panel o la pestaña.
- Captura la configuración original y proporciona un modo Original reversible.
- Explicación “Cómo funciona” integrada para cada optimización.

El script no modifica paquetes WebSocket, matchmaking, puntería, hitboxes,
visibilidad ni mecánicas. Tampoco reemplaza requestAnimationFrame con
temporizadores agresivos ni crea pings falsos.

Cada quinta apertura del juego muestra una bienvenida grande y cerrable de
Nexus Chat, siempre en inglés. Presenta de forma honesta las salas automáticas,
Global, Nexus ID persistente, amigos y conversaciones privadas. “Explore Nexus
Chat” abre únicamente la web oficial https://wnexuschat.netlify.app/ y requiere
un clic explícito; el userscript nunca descarga archivos. La × y “Not now”
cierran solo la aparición actual. No contiene seguimiento, enlaces de afiliados,
código ejecutable externo ni redirecciones automáticas.
