# Nexus 75 Optimizer changelog

## 1.3.0

- Added a bilingual Community Hub for Nexus Chat, Discord, support, feature
  requests and release notes.
- Added honest, copyable performance results and privacy-safe diagnostics.
- Added portable `NX75` profile codes. They contain optimization switches and
  the FPS target only; importing changes the draft until the user applies it.
- Added one-time, neutral feedback after several stable sessions.
- Added a short changelog shown once per installed version.
- Added a contextual Nexus Chat invitation after copying a performance result.
- Added **Don't show again** to the five-launch Nexus Chat welcome, plus a local
  re-enable control.
- Declared the Nexus Chat promotion through `@antifeature ads`.
- Kept all community state local. There is no telemetry, remote executable code
  or automatic update service.

## 1.2.0

- Reworked the Nexus Chat welcome into an English-only product preview.
- Changed the welcome frequency to every fifth game opening.
- Kept the call to action website-only with no direct file download.

## 1.1.0

- Opened the optimizer panel automatically.
- Added English and Spanish interface content.
- Added the initial dismissible Nexus Chat promotion.
